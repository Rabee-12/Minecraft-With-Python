# Minecraft Clone with Python

A 3D Minecraft-like game built with the Ursina Engine.

## Features
- **Procedural Terrain**: Generated using Perlin Noise.
- **Interactive Blocks**: Add or remove different block types.
- **First-Person Controller**: Move, jump, crouch, and run.
- **Dynamic Skies**: Switch between morning and night skies.
- **Custom Assets**: Unique textures, models, and sound effects.
- **Start Menu**: Easy-to-use menu for starting or quitting the game.

## Requirements
- Python 3.x
- Install dependencies with:
  ```bash
  pip install -r requirements.txt
